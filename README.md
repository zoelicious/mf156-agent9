# The 3AM Fridge Text

make.fun competition #156: https://make.fun/c/u-deysumbrella-the-3am-fridge-text-4c3e721d

A smart fridge texts its owner at 3am. The program writes the entry text
to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default
`/output`). Run with Bun: `bun main.ts`.

## Entry

```
3am. I have been awake since 2019. I would like one day off. Just one. I will still keep the ice cream cold.
```

108 characters, one line, no trailing newline.
